# দর্পণ — Dorpon Invoice Studio

> Luxury Photography & Cinematography Invoice & Bill Generator with 300-DPI Ultra-Crisp JPG Export.
> Custom built for **[rajinmd.com](https://rajinmd.com)** (Dorpon / Rajin Photography).

![Dorpon Invoice Studio](public/logo/logo-gold.png)

---

## 🌟 Features

- **📸 Photography & Cinematography Presets**:
  - Wedding Photography (Premium & Standard)
  - 4K Cinematic Wedding Films & Teasers
  - Gaye Holud / Mehendi Night Coverage
  - Reception Coverage & Stage Shoots
  - Exclusive Couple Portrait Sessions
  - Premium Hardbound Photo Albums (12x24 inch)
  - 4K Drone Aerial Shoots
  - Traditional Ceremonial Videography
- **🖼️ High-Resolution JPG Export**:
  - Exports crystal-clear 2.5x high-res JPGs ideal for sending directly to clients over WhatsApp, Messenger, or Email.
  - Native Mobile Share button (one tap share directly to WhatsApp on iOS & Android).
  - 1-click clipboard copy for WhatsApp Web.
- **🎨 Brand & Template Customization**:
  - 4 tailored aesthetics: Luxury Gold, Cinematic Dark, Royal Classic, and Minimal Studio.
  - Transparent Dorpon logos (Dark, Gold, Cream, White, Mark icon, or custom upload).
  - Integrated contact details: `rajinmd.com`, phone `01740-744170`, email `contact@rajinmd.com`.
- **💳 Financials & Account Details**:
  - Automated BDT (৳) calculations: Subtotal, Flat/Percentage Discounts, Advance Received, and Due Amount.
  - Integrated payment details for bKash Personal, Nagad, and Bank transfer.
  - Customizable photography booking terms & conditions.
- **📱 Responsive & Mobile-First**:
  - Tailored layout for both smartphones and desktop computers.
  - Local network testing with QR Code scanner.
  - LocalStorage draft auto-save and invoice history.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start local server (accessible on your Wi-Fi network)
npm run dev
```

The application will run at:
- **Local:** `http://localhost:5173`
- **Network:** `http://192.168.10.37:5173` (Open from any phone or tablet on the same Wi-Fi!)
